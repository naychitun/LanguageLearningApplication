# Language Learning App

Language Learning App for vocabulary study.

Developed a multilingual language learning web application using JavaScript, implementing quiz generation, speech synthesis, progress tracking, level management, and responsive user interface design.

## Overview

Language Learning App is a multilingual web application designed to help users learn vocabulary through interactive quizzes, pronunciation support, and progress tracking.

The application supports multiple languages, including Japanese, English, Myanmar, Chinese, Nepali, Bengali, and Vietnamese. Users can study vocabulary, listen to pronunciations, take quizzes, save favorite words, and monitor their learning progress through statistics and level-based learning.

## Features

* Multi-language vocabulary learning
* Interactive quiz system
* Speech synthesis for pronunciation practice
* Favorite words management
* Learning statistics dashboard
* Level progression system
* Light and dark mode support
* Responsive user interface

# 日本語バージョン

## 概要

Language Learning App は、多言語学習を支援するために開発した Web アプリケーションです。

ユーザーは単語学習、音声再生、クイズ学習を通じて効率的に語学を学ぶことができます。学習状況はダッシュボードや統計画面で確認でき、レベルアップ機能によって継続的な学習意欲を高めることができます。

本アプリは、日本語、英語、ミャンマー語、中国語、ネパール語、ベンガル語、ベトナム語の7言語に対応しています。

## 開発目的

日本で学習・生活する外国人が、複数言語を利用しながら効率的に語学学習を行える環境を提供することを目的として開発しました。

また、Webアプリケーション開発技術やJavaScriptによるフロントエンド開発スキルの向上を目的として制作しました。

## 主な機能

### 1. 単語学習機能

* 多言語の単語を一覧表示
* 課ごとに単語を分類
* 日本語・英語・ミャンマー語・中国語・ネパール語・ベンガル語・ベトナム語を表示

### 2. 音声再生機能

* Web Speech API を利用
* 各言語の発音を音声で確認可能
* 発音速度の変更に対応

### 3. クイズ機能

* 学習レベルに応じた問題を自動生成
* ランダム出題
* 正解・不正解の判定
* スコア表示機能

### 4. レベルシステム

* クイズ結果に応じてレベルアップ
* 学習進捗を可視化
* 次のレベルを表示

### 5. お気に入り機能

* 重要な単語を登録
* お気に入り一覧で管理

### 6. 学習統計機能

* 学習時間の記録
* 学習単語数の表示
* クイズ正解率の表示
* 学習履歴のグラフ表示

### 7. UI機能

* タブ切り替え
* レスポンシブデザイン
* ダークモード対応
